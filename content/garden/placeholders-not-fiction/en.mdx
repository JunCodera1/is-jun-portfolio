When a personal site has no content yet, it is tempting to fill the gap with confident, generic sentences. This site does not.

## The rule

A section that has not been written by its owner shows a dashed box that says so. Facts that can be checked — for example, which technologies a repository uses — are shown together with the file that proves them.

## Why it matters

- A visitor can always tell what was written by a person and what is a stand-in.
- Nothing on the page can be mistaken for an achievement that never happened.
- Filling the boxes in later is a data-file edit, not a redesign.
