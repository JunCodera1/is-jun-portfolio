この記事は個人的な体験談ではなく、設計上の判断の記録です。後から翻訳を足すのではなく、最初のコミットから三言語対応で作りました。サイト自身についての初期コンテンツです。

## 言語ごとに専用の URL

すべてのページは `/en`、`/ja`、`/vi` の下に存在します。`/ja/projects` へのリンクは、ブラウザーの設定にかかわらず、常に日本語のプロジェクト一覧を開きます。そのため共有しやすく、検索エンジンにも伝わりやすく、挙動も分かりやすくなります。

ブラウザーの言語が使われるのは、アドレスの入口 `/` に来たときの一度だけです。切り替えボタンで言語を選んだあとは、その選択が記憶されて優先されます。

## 翻訳がないときの扱い

ページが翻訳済みのふりをすることはありません。状態は三つあります。

| 状態 | 意味 | 訪問者に見えるもの |
| --- | --- | --- |
| 翻訳済み | その言語で書かれ、確認済み | 追加の表示なし |
| 下書き | 存在するが、まだ確認されていない | 「翻訳（下書き）」の注意書き |
| 未翻訳 | その言語の文章がまだない | 英語の原文、注意書き、原文へのリンク |

代わりに表示される文章には正しい `lang` 属性を付けているため、スクリーンリーダーが正しい発音で読み上げます。

## 検索エンジン向けのメタデータ

各ページは自分の正規 URL を宣言し、ほかの二言語版を `hreflang` で、英語を指す `x-default` とあわせて示します。サイトマップには、すべてのページの全言語版が載っています。

## 書式も言語に合わせる

日付、数字、読了時間は訪問者の言語に従います。日本語の読了時間は、単語を数えるための空白がないため、文字数から見積もっています。

```ts
// 読了時間：日本語は文字数、それ以外は単語数
const minutes = lang === "ja" ? Math.round(chars / 500) : Math.round(words / 200);
```

## まだ残っていること

このサイトの日本語・ベトナム語の文章は自然に読めるよう書いていますが、持ち主による確認がまだのため、それまでは下書きと表示しています。
