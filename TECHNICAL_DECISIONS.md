# Technical decisions

Each entry: decision → why → consequence. Newest decisions are appended.

1. **Next.js 16 App Router, React 19, TypeScript 5.9.** Row 40 asks for stable versions compatible with the environment. TypeScript 7.x is npm's `latest` but is a native rewrite that Next 16 does not declare support for, so 5.9 is pinned. The installed Next ships its own docs (`node_modules/next/dist/docs`); conventions such as `proxy.ts` (replacing `middleware.ts`) and async `params` were taken from there, not from memory.
2. **next-intl 4 with `localePrefix: "always"` and a `proxy`.** Every URL carries its locale. The proxy redirects only the bare `/` (cookie → `Accept-Language` → `en`), so browser language is an initial suggestion and a saved choice wins. All pages use `setRequestLocale` + `generateStaticParams` → fully static. Missing/malformed message keys throw at build (`onError`), never render a raw key.
3. **Tailwind 4 driven by CSS tokens; no shadcn/ui.** Row 41: don't depend on a component library when it hurts originality. The few controls (dialogs, radio group, combobox) are hand-built on native elements (`<dialog>`, `role=radiogroup`, `role=combobox`).
4. **CSP without nonces.** Nonces force dynamic rendering for every page (Next docs, *Content Security Policy*). The site is static, so scripts allow `'unsafe-inline'` (needed for Next's bootstrap and the no-flash theme script); everything else is locked down: same-origin only, no framing, no plugins, same-origin forms. The exposure is small because there is no user-generated content and no third-party script. Experimental SRI hashing was rejected (experimental, build-only).
5. **Content in Git.** Typed data files + MDX + JSON catalogs. No CMS/DB/auth: none is justified (row 47). Frontmatter is validated with zod at build.
6. **Fonts.** Space Grotesk, Inter, JetBrains Mono via Fontsource (all ship Vietnamese subsets, unicode-range lazy-loaded). Japanese uses a system stack (Hiragino / Yu Gothic / Meiryo / Noto Sans CJK). Local fallback faces carry `size-adjust`/`ascent-override`/`descent-override` computed from the fonts' metrics, which took the Vietnamese garden page from CLS 0.157 to 0.
7. **Motion without a JS animation library.** Reveal-on-scroll is CSS scroll-driven animation (`animation-timeline: view()`), transform-only so text is never dimmed; hover/press are CSS transitions; `prefers-reduced-motion` disables everything globally. The `motion` package was installed, found unnecessary and removed.
8. **GitHub data.** Public API only, server-side, `revalidate: 3600`, optional server-only token, and a committed snapshot (`npm run snapshot:github`) as the fallback. The snapshot is also the evidence for timeline/profile statistics. Every project fact was verified from manifests/trees/source (see PROJECTS_REVIEW.md), not from READMEs.
9. **Owner override of the design rows (06-01, 06-05).** The spreadsheet asks for "editorial, minimalist, subtle futuristic" and warns against excess. The owner then asked for an **anime/manga** look. Both are honoured as far as they can be: the editorial grid, tokens and restraint remain; the manga layer (ink outlines, hard shadows, screentone, speed lines, speech bubbles, chapter numbering, hanko logo, petals) sits on top. Those two rows therefore stay at IMPLEMENTED: whether the result still feels "not template-like" is the owner's judgement.
10. **Original characters and assets only.** Anime characters, logos, music and layouts from existing franchises are not reproduced. Mascots and decorations are drawn as original SVG. Style references are used only at the level of general visual grammar.
11. **Placeholders are a first-class UI state.** Anything the owner must supply renders as a dashed, hatched "blank panel" slot labelled as a placeholder, never as plausible content (rows 51–52).
12. **Contrast is a tested property.** `tests/unit/contrast.test.ts` parses `globals.css` and enforces WCAG ratios for every text/background pair in both themes. The spec's lime accent is a *fill*; as text on the light theme it would fail, so the light theme has a separate darker `--accent-fg`.
