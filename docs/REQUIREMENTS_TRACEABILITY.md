## How to read this

* **IDs.** The spreadsheet's IDs are per *group* (01–11), not per row, so stable IDs `REQ-<group>-<n>` were generated; the original Excel row number is kept in the first column.
* **Priorities.** Spreadsheet level → tier: *Bắt buộc* → **P0**, *Nên có* → **P1**, *Tùy chọn* → **P2**, *Thử nghiệm* → **P3**. Stack rows marked *Đề xuất chính* are treated as **P0** (foundation) and *Đề xuất* as **P1**. Rows 62–65 (*Cần chủ website cung cấp*) are **OWNER** inputs. The spreadsheet wins over the master prompt where they differ (e.g. the prompt lists the library and GitHub integration at P1; the sheet marks them optional).
* **Statuses.** `IMPLEMENTED` code exists · `TESTED` relevant automated tests ran and passed · `VERIFIED` acceptance criteria checked with evidence · `DEFERRED` postponed on purpose, with a reason · `BLOCKED` waiting on something outside the code.
* **Compound rows.** Many rows bundle several acceptance criteria. A row can only be TESTED/VERIFIED when **no part is open** (the generator enforces this); open parts are listed under *Open parts* and keep the row at IMPLEMENTED.
